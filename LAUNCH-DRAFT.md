## Product positioning

An agent companion that makes usage and task state visible, starting with Codex on macOS. Built together by Tori and Codex, adapted from Claude-Meter with source credits retained. One tiny crab, seven consistent pixel scenes and Tori Patterns character landscapes.

Current support: **Codex on macOS Apple Silicon**. Other agents are a future integration direction, not a supported feature in this version. The displayed percentage is an account quota window, not a token balance or API credit balance.
